# BlogToolStack

live in `../04_pinterest_affiliate_handoff/goal.md` (this folder implements
that spec). Site is Astro + Cloudflare Pages; `pipeline/` holds the keyword
backlog tool and the article validator; `content-backlog/` holds the keyword
backlog and reference files (Kit affiliate link, etc.).

Weekly content process: see `pipeline/weekly-batch-runbook.md`.
