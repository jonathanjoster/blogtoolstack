# Pin & Schedule Runbook

For each article in this week's batch:

1. Create a new Pin in Pinterest Business, using the matching PNG
   from `assets/pins/`.
2. Title: reuse the article's `title` frontmatter field (trim if over
   Pinterest's limit).
3. Description: 1-2 sentences including the target keyword naturally,
   plus a soft call to action ("Save this for later").
4. Destination link: the live article URL on blogtoolstack.com (never
   link directly to the Kit affiliate URL from the pin itself -- see
   goal.md's non-negotiable platform-risk rule).
5. Board: file into the most relevant existing board, or create one if
   none fits (e.g. "Blogging Tools").
6. Use Pinterest's native scheduler to spread this batch's pins across
   the coming week rather than posting them all at once (target: >=1
   pin/day per goal.md's cadence decision).
